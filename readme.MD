# Arte & Alma

Proyecto web estático de una galería de arte en línea, desarrollado como parte de la Evaluación 2 del taller de tecnologías web. El sitio fue actualizado para implementar Bootstrap 5 y mejorar la presentación, organización y respuesta móvil del contenido.

## 📖 Descripción

Este proyecto presenta una galería artística llamada "Arte & Alma" con tres secciones principales:

- Página de inicio con presentación institucional y llamada a la acción.
- Galería con obras destacadas y tarjetas visuales responsivas.
- Formulario de contacto para consultas, compras o ventas.
- Navegación moderna con estilos de Bootstrap.
- Diseño adaptable para desktop y dispositivos móviles.

## 🗂️ Estructura del proyecto

- `index.html` — página principal de presentación.
- `galeria.html` — sección con obras y compra visual.
- `contacto.html` — formulario de contacto.
- `assets/css/style.css` — estilos personalizados del proyecto.
- `assets/img/` — imágenes del sitio y obras de arte.
- `instrucciones/` — documentos de la evaluación y rúbrica.

## ▶️ Cómo ejecutar

Como es un proyecto estático, no requiere instalación de dependencias.

1. Abre la carpeta del proyecto en tu navegador.
2. Ejecuta `index.html` directamente o usa un servidor local.

Ejemplo con Python:

```bash
python -m http.server 8000
```

Luego abre en el navegador:

```text
http://localhost:8000
```
